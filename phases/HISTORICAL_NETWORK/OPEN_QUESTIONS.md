### OQ-002: Giovanni Fontana's Cipher — LARGELY RESOLVED

**Resolved (2026-02-28):**
- [x] 23 symbols constructed exclusively from circles + straight lines
- [x] Vowels: circle base + directional tickmarks (cardinal mnemonic: A=east, E=north, I=plain, O=south, U=west)
- [x] Consonants grouped by morphological similarity (mirror group B/D/P/Q, stroke-count M/N/H/K, loop S/T)
- [x] Battisti & Saccaro (1984) fully deciphered it: simple monoalphabetic Latin substitution
- [x] Fontana's cipher is deliberately mnemonic — designed for recall, not cryptographic security
- [x] **MAJOR FINDING: Galeazzo di Santa Sofia (P011) was Fontana's degree promoter** — arts 1418, medicine 1421. Galeazzo spent 1394-1405 at Vienna as personal physician to Duke Albrecht IV. This is a documented one-hop connection between a Padua cipher-maker and the Vienna court during the Voynich radiocarbon window.
- [x] Other Fontana promoters: Antonio Cermisone, Bartolomeo da Montagnana, Paolo Nicoletti da Udine, Prosdocimo de Beldomandi
- [x] No published Voynich comparison exists
- [x] Glyph-level resemblances: moderate at best (Fontana I ≈ EVA o, Fontana S ≈ EVA l, Fontana M/N parallel strokes ≈ EVA minims). But no gallows equivalents, no vertical tier structure.

**Still needed:**
- [ ] Did Fontana's cipher influence others? Any successors or imitators?
- [ ] Fontana's Secretum de thesauro (BnF) — mnemonic systems and combinatorial machines; relevant to systematic symbol design

**Assessment:** Fontana's cipher itself is too simple to be the Voynich cipher. But Fontana is proof that the cultural practice of designing invented scripts for illustrated technical manuscripts existed in exactly the right place, time, and profession — with documented personal connections to Vienna.

### OQ-007: Mellon MS 27 — Yale's Other Cipher Manuscript — RESOLVED

**Resolved (2026-02-28):**
- [x] **Simple number-substitution cipher** (Arabic numerals standing for letters) — trivially solvable
- [x] Cipher added c.1586 by **Martin Roesel of Rosenthal** to selected recipe passages; bulk of MS is clear text
- [x] Three chronological layers: core c.1520, Wolfgang the Organist (Usedom, 1536), Roesel additions (c.1586)
- [x] At least 7 scribal hands total
- [x] Content: alchemical texts (Albertus Magnus attrib., Khalid ibn Yazid attrib., Theodoric), medical recipes
- [x] Provenance: South German paper → Usedom (Pomerania) → Roesel → Duveen → **H.P. Kraus** (1949) → Yale/Beinecke (1965)
- [x] Both Mellon MS 27 and Voynich passed through H.P. Kraus's hands (coincidental — Kraus handled thousands of MSS)
- [x] No published comparison with Voynich exists — cipher systems fundamentally different
- [x] **No invented glyphs, no visual EVA resemblance whatsoever**
- [x] Rec's 2014 Societas Magica paper: cipher protected perfected alchemical recipes; broader secrecy ecosystem of Decknamen + symbols + visual-verbal integration
- [x] No connection to Vienna, Austrian monasteries, or Melk Reform network

**Assessment:** NEGATIVE COMPARAND. Shows what a "normal" alchemical cipher manuscript looks like — making the Voynich's anomaly more precise. Clear-text majority, selective encryption, standard number substitution, identifiable language. Voynich violates every one of these norms.
