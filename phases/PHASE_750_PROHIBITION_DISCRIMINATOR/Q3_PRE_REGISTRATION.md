Extract F1–F4 for the same Testamentum recipes from BOTH Catalan and Latin originals (English as
comprehension aid only, ordering statements verified against original). The prohibition SHAPE is a

- **Shapes agree** (per matched recipe, on the subset both attest) → procedure-property, proceed.

## STAGE 1 — THE GATE (NL-internal, register-free, BEFORE the Voynich)
1. **Per-recipe graph-density floor (Risk A, lean):** a recipe's prohibition graph must have ≥ K=3
   attested ordering constraints to be ESTIMABLE. Below → NON-ESTIMABLE, excluded (NOT coarsened).
   Report survival count per corpus.
2. **Discrimination + register-invariance (one test, both confounds):** do the two distillation
   corpora (Testamentum + Brunschwig) CO-CLUSTER and SEPARATE from non-distillation (Theophilus
   [+Geber]) on F1–F4, ACROSS the register divide, beyond a ≥1000-iteration corpus-label-shuffle
   null (p<0.05)?
   - This simultaneously = (a) the C2052 discrimination check (do features separate process at
     all?), (b) register-invariance proof (distillation co-clusters DESPITE register → register
     doesn't drive shape → Risk B empirically dead), (c) the Testamentum-vs-Brunschwig diagnostic.
3. **Leave-one-feature-out:** the separation must survive dropping any single feature (else it is
   one-bit-driven — the C2041 single-leg trap; report as such).
- **GATE FAILS** (distillation doesn't co-cluster, OR doesn't separate from metalwork, OR register
  drives the clustering, OR one-bit-driven) → **crib is DEAD. STOP. No Voynich scoring.** A clean,
  cheap NEGATIVE about the METHOD (crib = C2052 redux), not about the Voynich.
