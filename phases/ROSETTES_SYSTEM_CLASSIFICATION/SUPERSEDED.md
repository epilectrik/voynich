# SUPERSEDED

**This phase has been superseded by Phase 402 (ROSETTES_SYSTEM_REVALIDATION).**

Phase 387/388H (ROSETTES_SYSTEM_CLASSIFICATION) was built on incomplete EVA transcript data that was missing ring text for 3/9 rosettes and lacked spatial context. All 21 constraints derived from this phase and its successors (C1088-C1098, C1100-C1101, C1109-C1115, C1122-C1123) were deleted in v4.10.10.

Phase 402 revalidated the Rosettes foldout using corrected ZL transcription data (`data/rosettes_annotated.json`) and produced 5 new constraints (C1124-C1128).

See: `phases/ROSETTES_SYSTEM_REVALIDATION/` for the replacement analysis.
