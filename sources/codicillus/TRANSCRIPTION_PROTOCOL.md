# Codicillus Transcription Protocol

## Source
- **Manuscript:** Pseudo-Lull Codicillus, Science History Institute, pv54euh
- **Date:** c. 1470-1500, Northern Italy
- **Language:** Latin (manuscript hand, not print)
- **Images:** 227 JPGs in `sources/codicillus/`
- **Text pages:** ~pages 6-200 (pages 1-5 are covers/blanks, 201+ are spine/back)

## Method
Parallel agent transcription from manuscript images, following the same
approach used for the PL Testamentum (97 chunks, 8 agents per batch).

### Step 1: Transcription (Latin)
- Each agent receives 3-5 page images
- Task: transcribe the Latin text as accurately as possible
- Include page numbers from manuscript (red numerals in margins)
- Mark unclear/illegible passages with [?]
- Preserve line breaks approximately
- Note diagram pages as [DIAGRAM: brief description]
- Red ink text should be marked with {red: text}

### Step 2: Translation (Latin → English)  
- Chunked parallel translation (same as PL method)
- Preserve chapter/section divisions
- Keep cipher letters (A. B. C. etc.) as-is, don't translate them
- Preserve technical alchemical terms with [Latin: term] on first use

### Batch Structure
- Pages 6-40: PRIORITY (contains cipher key, diagrams, Rota)
- Pages 41-100: Theory and methodology
- Pages 100-200: Extended practical content

## Quality Notes
- This is manuscript hand, NOT print — expect harder reads than PL
- Red ink sections are chapter headers and key definitions
- Marginal annotations in different hands — note but transcribe separately
- Some pages have water damage (visible staining on edges)
