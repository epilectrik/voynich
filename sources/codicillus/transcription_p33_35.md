# Codicillus Pages 33-35 — Operations, Wheels, Network

## Page 33: Nine Operations (3x3 Grid)

| | Column 1 | Column 2 | Column 3 |
|---|----------|----------|----------|
| **Row 1** | Liquefaccio | Elementacio | Diuisio |
| **Row 2** | Infissimacio | Distillacio | Calcinacio |
| **Row 3** | Inuencio | Coagulacio | Sublimacio |

Text between rows explains these are the operations of the "second distinction"
through which the regimen is made. Operations proceed in order from liquefaction
through sublimation.

## Page 35: Network Diagram

Central hub: **lapis** (the stone)

Surrounding nodes connected by curved lines:
- **terra** (earth, top)
- **aqua** (water, center-left)  
- **aer** (air, right)
- **ignis** (fire, lower-right)
- **mercurius** (mercury, upper-middle)
- **arboris** (tree, lower-middle)

Perimeter letters: k, f, o, p, q, B, f, d, g, n, l
These index back to the combinatorial wheel system on page 34.

Corner annotations:
- "aqua seminalis" (seminal water)
- "aer exubecatus" (exuberant air)

The network maps the PATH from raw elements through operations to the stone.
