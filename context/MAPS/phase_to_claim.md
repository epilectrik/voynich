# Phase to Claim Mapping

**Purpose:** Find which constraints a phase produced

---

## How to Use

Look up phase to find constraints it produced.

> **Status note (v7.25):** this map records **provenance only**; it does not give a constraint's current status. Look status up in the generated `context/CONSTRAINT_TABLE.txt` (a number missing from it is dead; Tier 3 means demoted or speculative) and the reason in `context/CLAIMS/INDEX.md`. Rows containing demoted or dead constraints are annotated. Withdrawn constructs: SYSTEM/STATUS_BRIEF.md §3. The group headings "Closure" and "Saturation Frontier" are historical phase-group labels, not current status (closure language is retired, strategic review §5).
