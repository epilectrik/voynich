# Pre-Registration Predictions for Unmatched Voynich Folios

**Date:** 2026-04-12
**Status:** PRE-REGISTERED (predictions made BEFORE SISMEL Catalan Testamentum examined)
**Purpose:** Falsifiable predictions derived from structural features of 42 unmatched Currier B folios, using patterns validated on 41 matched folios (Phases 628-639, C1925-C1958).

**Validation protocol:** When the SISMEL critical edition (Pereira-Spaggiari 1999) is photographed and analyzed, score each prediction against the Catalan recipe text. Predictions are scored YES/NO/PARTIAL. A finding is considered validated if >70% of testable predictions score YES or PARTIAL.

**What these predictions are based on:**
- dar = material introduction event (C1925, validated 6/6, extended to 21/21 matched folios)
- fch = mercurial solvent marker (C1943, validated on all mercury-recipe folios)
- cs = gold/silver marker (C1947, validated on gold-recipe folios)
- e_depth = thermal intensity (lower = harsher, higher = gentler/balneum)
- PREFIX distribution = operational profile (qo=thermal, sh=monitoring, ch=testing, ok=vessel, ot=transfer)
- Section B = Mercuriorum preparation, Section S = transmutation/multiplication (C1927, C1930)
- chekar = post-thermal quality check (C1926)
