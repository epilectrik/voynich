# C1290: Paragraph Category Composition Predicts Mode

**Tier:** 2
**Scope:** B
**Phase:** CATEGORY_MECHANISM_DECOMPOSITION (Phase 455)
**Date:** 2026-02-24

## Statement

Paragraph-level category composition predicts Mode A vs Mode B (C1231 suffix centroids). Mode A paragraphs: THERMAL 28.8%, TRANSITION 11.5%. Mode B paragraphs: THERMAL 21.0%, TRANSITION 16.7%. Chi2=300.4, V=0.114, p<0.001. N=175 Mode A paragraphs, 309 Mode B paragraphs.

## Architecture

- **Confirms C1279 at paragraph level.** C1279 showed mode A = THERMAL-enriched, mode B = TRANSITION-enriched at folio level. C1290 confirms this holds at the finer paragraph granularity with a strong effect (V=0.114).
- **Mode = category emphasis.** Mode A (terminal-suffix dominant) = THERMAL-heavy operational theme. Mode B (bare-suffix dominant) = TRANSITION-heavy operational theme. The suffix mode classification and category system, derived independently, converge on the same operational axis.
- **Paragraph-level operational programs.** Combined with C1287 (header marking enrichment) and C1288 (folio coherence), the picture: each paragraph is a mode-specific operational program (A=heating, B=transitioning) within a folio-coherent theme, preceded by marking/staging specification.

## Provenance

- Extends C1279 (mode-category differentiation) from folio to paragraph level
- Connects C1231 (suffix mode centroids) with C1250 (8-category system)
- Complements C1287 (paragraph header marking) and C1288 (folio coherence)
