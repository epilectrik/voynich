# C1508: Bridge category redistribution -- A arrangement/monitoring, B thermal/operation

**Tier:** 2
**Scope:** GLOBAL, A->B, MIDDLE, atom, bridge, category, redistribution, THERMAL, STAGING
**Phase:** BRIDGE_ATOM_STABILITY (Phase 539)
**Dependencies:** C1499, C1503, C1347, C1505, C1250

## Constraint

Bridge MIDDLEs preserve the SAME category identity across A and B (100% match rate -- every bridge MIDDLE gets the same category in both systems), but their token-weighted category distribution shifts systematically. Category JSD = 0.037 (cosine = 0.913).

A category distribution: STAGING 24.4%, TRANSITION 19.1%, FLOW 16.9%, THERMAL 13.5%, OPERATION 9.4%, CONTAINMENT 5.2%, MONITORING 5.2%, MARKING 4.0%.
B category distribution: THERMAL 23.6%, FLOW 19.9%, TRANSITION 16.9%, OPERATION 15.2%, STAGING 13.3%, CONTAINMENT 5.4%, MARKING 3.7%, MONITORING 1.4%.

The shift is: THERMAL +10.1pp (largest gain), OPERATION +5.8pp, STAGING -11.1pp (largest loss), MONITORING -3.8pp. B amplifies execution categories (THERMAL, OPERATION) while A amplifies arrangement/observation categories (STAGING, MONITORING). This is consistent with C1347 (B reshapes bridge category usage) but now quantified at the bridge-specific level.

Per-HEAD category stability varies dramatically: o-HEAD is most stable (JSD = 0.004), a-HEAD stable (JSD = 0.013), t-HEAD stable (JSD = 0.015), k-HEAD moderate (JSD = 0.045), HEADLESS moderate (JSD = 0.038), e-HEAD most unstable (JSD = 0.166). e-HEAD's instability is driven by the edy MIDDLE (A: 7 tokens, B: 1,938 tokens -- 277x enrichment) which shifts e-HEAD from balanced to OPERATION-dominated in B.
