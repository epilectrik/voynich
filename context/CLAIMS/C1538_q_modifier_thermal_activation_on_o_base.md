# C1538: q-Modifier Uniquely Activates THERMAL Channel on o-Base (64% k-HEAD vs 5-19% for Other Modifiers)

**Tier:** 2
**Scope:** B, PREFIX, atom, modifier, q, o-base, THERMAL, k-HEAD, compositional, qo, C1300, C1313, C1536, C1537
**Phase:** PREFIX_ATOM_TAXONOMY (Phase 544)
**Date:** 2026-03-06

## Claim

Within o-base PREFIXes, the q-modifier uniquely selects k-HEAD at 64.0% (plus 20.3% t-HEAD = 84.3% thermal/flow combined). All other modifiers paired with o-base produce 65-87% headless tokens with only 5-19% k-HEAD. The q-modifier is the ONLY modifier that activates the thermal channel on o-base. qo is genuinely COMPOSITIONAL: q carries the thermal activation signal, o provides the domain base. This resolves qo's special status -- it is not a lexicalized opaque unit but a transparent modifier+base combination.

## Evidence

### Modifier effects within o-base (B tokens)

| Modifier + o | k-HEAD % | t-HEAD % | Headless % | N |
|---|---|---|---|---|
| **q**o | **64.0** | **20.3** | 11.1 | 4,069 |
| so | 18.5 | 2.1 | 73.0 | 189 |
| to | 15.7 | 4.3 | 67.0 | 115 |
| po | 8.1 | 1.5 | 65.4 | 136 |
| do | 4.8 | 3.2 | 86.5 | 126 |
| ko | 6.2 | 6.2 | 79.2 | 48 |

q-modifier produces 64% k-HEAD; the next highest modifier (s) produces only 18.5% k-HEAD (3.5x gap). Without q, o-base defaults to HEADLESS (65-87%). The q-modifier does not merely increase k-HEAD slightly -- it fundamentally transforms the o-base from a headless channel to a thermal channel.

### Contrast with a-base (C1537)

On a-base, ALL modifiers produce ~95% headless. On o-base, q produces 64% k-HEAD while all others produce 65-87% headless. The o-base is the modifier-SENSITIVE base (75pp spread), while a-base is modifier-INSENSITIVE (1.5pp spread). q's thermal activation power is specific to the o-base context.

## Interpretation

qo's near-pure THERMAL channel (C1300: qo = 84% thermal/flow) is now decomposed to its atom-level mechanism: q carries thermal activation, o provides the base. This is consistent with the Tier 4 Latin gloss qo = coquo "I boil/cook" where q = "cook" and o = "vessel/arrange." The transparency of qo as a compositional unit extends C1193 (PREFIX compositional duality) by showing that at least one "emergent" PREFIX (qo) is actually compositionally transparent at atom resolution. The q-modifier may derive from a different etymological source than other modifiers, explaining its unique thermal activation power.

## Falsification Criteria

1. If another modifier on o-base produces >40% k-HEAD
2. If q on a different base produces comparable k-HEAD activation (>50%)
3. If the q-modifier effect is fully explained by a confound (e.g., section or REGIME)
