# C1382: k/a Atom-Initial Suffix Mode Polarization

**Tier:** 2
**Scope:** B
**Phase:** GLOSS_PREDICTION_TESTS (Phase 495)
**Date:** 2026-03-02

## Statement

The initial atom of a MIDDLE predicts suffix mode polarization. k-initial MIDDLEs are 0.583x depleted in Mode B lines versus Mode A lines (chi2=245, p<0.0001), consistent across all five sections (B=0.56x, C=0.61x, H=0.63x, S=0.67x, T=0.45x). a-initial MIDDLEs show the opposite: 2.034x enriched in Mode B. e-initial and o-initial MIDDLEs are mode-neutral (0.986x and 1.030x). The two universal suffix modes (C1229) select for different MIDDLE-initial atoms: Mode A (specification/energy) concentrates k-initial vocabulary; Mode B (continuation/equilibration) concentrates a-initial vocabulary.

## Hypothesis Tested

The crazy-expert agent proposed that k encodes "heat" (from Kochen) and should concentrate in Mode A lines, which are THERMAL-enriched (C1309). If the atom-level gloss system is structurally real, the initial atom of MIDDLEs should predict which suffix mode line they appear on. This extends C1381 (o-initial predicts cross-system distribution) from the AZC/B axis to the Mode A/B axis within Currier B.

## Evidence

### T1: k-initial MIDDLE rate by suffix mode — PASS

| Mode | k-initial | Total | Rate |
|------|-----------|-------|------|
| A | 1,103 | 5,625 | 19.61% |
| B | 1,994 | 17,449 | 11.43% |

- B/A ratio: 0.583x
- Chi-squared: 245.0, p < 0.0001

### T2: Section control — PASS (all 5 sections consistent)

| Section | Mode A k-rate | Mode B k-rate | B/A ratio |
|---------|--------------|--------------|-----------|
| B | 26.56% | 14.93% | 0.562x |
| C | 14.75% | 8.95% | 0.607x |
| H | 12.00% | 7.60% | 0.633x |
| S | 16.75% | 11.26% | 0.672x |
| T | 15.66% | 7.09% | 0.452x |

No section drives the effect; all five show consistent k-initial Mode A enrichment.

### T3: Comparison atoms — k and a are polar opposites

| Atom | B/A ratio | Direction |
|------|-----------|-----------|
| k | 0.583x | Strong Mode A |
| a | 2.034x | Strong Mode B |
| e | 0.986x | Neutral |
| o | 1.030x | Neutral |
| d | 1.130x | Slight Mode B |
| h | 0.764x | Mild Mode A |

k and a are the maximally polarized atom pair. e (the grammar backbone atom) is perfectly neutral, confirming that mode polarization is atom-specific, not a general vocabulary effect.

## Relationship to Existing Constraints

- **C1229-C1231** (Tier 2): Establishes the two universal suffix modes. C1382 shows mode selection extends to MIDDLE-initial atoms.
- **C1309** (Tier 2): Mode A is THERMAL-enriched (28.8% vs 21.0%). C1382 identifies k-initial as the atom-level carrier of this category-mode alignment.
- **C1339** (Tier 2): THERMAL MIDDLEs lean Mode B in suffix behavior (0.406). C1382 is not contradictory — C1339 measured the suffix attached to individual tokens; C1382 measures which mode's lines the tokens appear on.
- **C908** (Tier 2): k-MIDDLEs correlate with HIGH_K kernel profile. C1382 connects this kernel affinity to paragraph-level mode cycling.
- **C1381** (Tier 2): o-initial predicts AZC enrichment (cross-system). C1382 shows k-initial predicts Mode A enrichment (within-system). Together they demonstrate that atom-initial position carries operational semantics along two independent axes.

## What This Does NOT Prove

- Does not prove k "means" heat or a "means" sustain (semantic ceiling, C171)
- Does prove that MIDDLE-initial atoms partition along the same axis as suffix modes, linking sub-MIDDLE syntax to paragraph-level program structure
- The a-initial Mode B enrichment (2.034x) is equally strong but was not the focus of the prediction; it is documented here as a symmetric finding
