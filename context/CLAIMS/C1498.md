# C1498: n/y-terminal categorical displacement exclusion

**Tier:** 2
**Scope:** B, MIDDLE, headless, displaced, HEAD, terminal, n, y, bare, exclusion, gate
**Phase:** DISPLACED_HEAD_GRAMMAR (Phase 537)
**Dependencies:** C1484, C1487, C1494, C1440

## Constraint

Terminal atom identity categorically gates whether HEAD-set atom displacement occurs in headless compounds. n-terminal and y-terminal near-categorically EXCLUDE displacement (0.36% and 0.39% respectively), while bare-terminal (no terminal atom) strongly PREDICTS displacement (83.9%). The full terminal displacement gradient: bare 83.9% > h 43.4% > l 48.5% > r 37.0% > m 18.2% > n 0.36% > y 0.39%.

## Mechanistic Explanation

n and y are CHANNELED terminals (C1487) with exclusive modifier partnerships (C1484): n pairs ONLY with i, y pairs ONLY with d. Since i and d are non-HEAD modifiers, the i+n and d+y combinations leave no compositional slot for a HEAD-set atom. HEAD-set atoms cannot function as modifiers in these contexts because the modifier slot is already occupied by the terminal's exclusive partner.

Bare-terminal tokens have no terminal atom to impose constraints, so HEAD-set atoms freely appear as the final element of the compound, functioning in their terminal role (especially k/t per C1478).

h-terminal (TRANSPARENT, C1487) shows intermediate displacement (43.4%) because h permits diverse modifiers {c,p,f,s} (C1484), some of which co-occur with HEAD-set atoms (e.g., ckh = c+k+h).

## Falsification

Would be falsified if displacement rates were uniform across terminal atoms rather than showing the observed 200x+ range (bare vs n/y).
