# C1484: TERMINAL Modifier Exclusivity

**Tier:** 2
**Scope:** B, MIDDLE, atom, TERMINAL, modifier, selectivity, partition
**Phase:** TERM_FUNCTIONAL_TAXONOMY (Phase 535)
**Date:** 2026-03-06

## Statement

Each terminal selects from a narrow modifier subset, creating near-exclusive modifier channels. n pairs only with i (i=8.606x enrichment, all others 0.0x — 3,553 i-instances, zero other modifiers). y pairs only with d (d=2.868x, all others <0.03x). h takes {c,p,f,s} (c=9.1x, p=7.7x, f=6.4x, s=5.0x; i=0.1x, d=0.1x). l/r/m resist modification entirely (modifier rate 1.8-3.8%). The modifier slot is fully TERMINAL-gated: knowing the terminal determines which modifiers are legal. This extends C1479 (HEAD modifier selectivity) to the TERMINAL dimension — HEAD and TERMINAL jointly constrain the modifier palette.

## Evidence

- **n-i exclusivity:** 3,553 i-modifier instances, 0 instances of any other modifier at n-terminal
- **y-d exclusivity:** d=2.868x enrichment, all other modifiers <0.03x
- **h modifier pool:** c=9.1x, p=7.7x, f=6.4x, s=5.0x; i and d excluded at 0.1x
- **l/r/m depletion:** All modifier enrichments <0.3x, modifier rates 1.8-3.8%
