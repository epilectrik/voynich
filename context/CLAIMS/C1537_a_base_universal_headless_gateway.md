# C1537: a-Base is the Universal Headless Gateway (94-96% Headless Regardless of Modifier)

**Tier:** 2
**Scope:** GLOBAL, PREFIX, atom, base, a-base, headless, gateway, modifier-independent, da, sa, ka, ta, C1488, C1491, C1524, C1536
**Phase:** PREFIX_ATOM_TAXONOMY (Phase 544)
**Date:** 2026-03-06

## Claim

All a-base PREFIXes (da, sa, ka, ta) produce 94-96% headless MIDDLEs. Modifier identity has NO effect on headless rate for a-base PREFIXes (range 94.5-96.0%, spread = 1.5pp). This is the most deterministic base-to-HEAD mapping in the system. The a-base categorically LOCKS headless status regardless of which modifier precedes it. C1491's da-PREFIX near-exclusivity (2,284x enrichment) is not special to 'da' -- it reflects the broader a-base headless gateway that all a-base PREFIXes share.

## Evidence

### Headless rates by a-base PREFIX (B tokens)

| PREFIX | Modifier | Headless % | N |
|---|---|---|---|
| da | d | 95.9 | 1,083 |
| sa | s | 96.0 | 329 |
| ka | k | 94.5 | 238 |
| ta | t | 95.8 | 237 |

Range: 94.5% - 96.0%. Spread: 1.5 percentage points. All four modifiers produce functionally identical headless rates.

### Comparison to other bases

| Base | Headless % | Modifier Spread |
|---|---|---|
| a | 95.8 | 1.5pp (94.5-96.0) |
| o | 11.1-86.5 | 75.4pp (modifier-SENSITIVE) |
| h | 6.0-32.0 | 26.0pp (modifier-sensitive) |
| k | 6.1-8.4 | 2.3pp (modifier-insensitive) |
| t | 11.6-36.0 | 24.4pp (modifier-sensitive) |

a-base has the narrowest modifier spread and the highest headless rate. k-base also has narrow spread but at low headless rates (6-8%). The a-base is the ONLY base where headless rate is both high AND modifier-independent.

## Interpretation

The a-base acts as a categorical headless gateway: once 'a' is chosen as the base, the resulting MIDDLE will be headless with >94% probability regardless of modifier. This generalizes C1491 (da-PREFIX near-exclusivity) from a single PREFIX to the entire a-base family. The modifier on a-base PREFIXes selects something OTHER than HEAD domain (likely positional or register properties per C1396). This is the atom-level mechanism underlying C1524 (headless PREFIX exclusivity universal).

## Falsification Criteria

1. If any a-base PREFIX produces <85% headless rate
2. If modifier identity explains >10% of headless variance within a-base
3. If a new a-base PREFIX type is found with significantly different headless rate
