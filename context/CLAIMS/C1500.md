# C1500: Bridge-dark HEAD domain differentiation

**Tier:** 2
**Scope:** B, A->B, MIDDLE, atom, HEAD, bridge, dark, pipeline, domain, differentiation
**Phase:** CROSS_LAYER_ATOM_DECOMPOSITION (Phase 538)
**Dependencies:** C1475, C1140, C1139, C1141, C1394

## Constraint

Bridge and dark pipeline MIDDLEs show complementary HEAD domain profiles despite sharing the same atom substrate. Bridge is enriched in executable HEAD atoms e/k/t (37.6% combined) relative to dark (31.0%), ratio 1.21x. Dark is enriched in arrangement HEAD o and headless types (63.3% combined) vs bridge (51.8%), ratio 1.22x. The o-HEAD enrichment in dark (28.7%) relative to bridge (16.5%) is the sharpest single-HEAD difference: 1.74x.

This HEAD differentiation is consistent with their functional roles: bridge carries the dynamical backbone (C1139) using executable domain HEADs (THERMAL via k, FLOW via t, balanced via e), while dark carries identification vocabulary (C1137) using arrangement and infrastructure HEADs.

## Falsification

Would be falsified if bridge and dark had identical HEAD distributions (JSD < 0.005), or if dark showed higher e/k/t rates than bridge.
