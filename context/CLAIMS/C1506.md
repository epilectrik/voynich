# C1506: Bridge MIDDLE terminal atom stability across A and B

**Tier:** 2
**Scope:** GLOBAL, A->B, MIDDLE, atom, bridge, terminal, stability, cross-system
**Phase:** BRIDGE_ATOM_STABILITY (Phase 539)
**Dependencies:** C1499, C1501, C1503, C1487, C1440

## Constraint

Bridge MIDDLEs (85 shared between A and B matching B grammar) preserve their terminal atom distribution across Currier A and Currier B with near-perfect fidelity. Token-weighted TERMINAL JSD = 0.014 (cosine = 0.977), the most stable slot dimension. Terminal tier distribution is also preserved (JSD = 0.005): BARE_TERM A=35.6% B=39.3%, CHANNELED A=45.0% B=46.8%, LOCKED A=13.8% B=10.8%, DIFFUSE A=5.7% B=3.1%.

y-terminal is the most B-enriched terminal (1.54x), while h-terminal is the most A-enriched (0.54x B/A ratio). All 7 terminal categories (bare, h, l, m, n, r, y) are shared across both systems with no system-exclusive terminals.

This establishes that the terminal atom -- the atom carrying suffix gating (C1440) and category specificity (C1487) -- functions identically in both registry (A) and execution (B) contexts, despite dramatic frequency differences in the MIDDLEs that carry them.

Token-weighted JSD = 0.014. Cosine = 0.977.
Terminal tier JSD = 0.005 (BARE_TERM, CHANNELED, LOCKED, DIFFUSE near-identical proportions).

For comparison: HEAD JSD = 0.077 (5.4x less stable), MODIFIER JSD = 0.048 (3.4x less stable), PREFIX ecology JSD = 0.072, SUFFIX ecology JSD = 0.153. Terminal is the most preserved dimension of bridge MIDDLE behavior.

## Falsification

Would be falsified if TERMINAL JSD exceeded 0.10, or if any terminal category appeared exclusively in one system.
